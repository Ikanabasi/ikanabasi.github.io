## Featured Project — DataOps Sentinel

### AWS Banking Data Engineering & Financial Monitoring Platform

**[Live Dashboard](https://data-ops-sentinel.streamlit.app/)** | **[GitHub Repository](https://github.com/Ikanabasi/data-ops-sentinel)**

DataOps Sentinel is an end-to-end data engineering and financial analytics platform I developed using real banking data from the Federal Deposit Insurance Corporation (FDIC).

The goal was to build more than a dashboard. I wanted to understand how financial data moves from an external API into a reliable analytical system, including ingestion, validation, transformation, cloud storage, monitoring, and presentation.

**Project highlights:**

- Processed **102,983 bank-quarter financial records** across 22 reporting quarters.
- Built a Bronze–Silver–Gold data architecture using Python and AWS.
- Implemented data-quality checks and automated tests.
- Developed eight SQL views for monitoring banking financial indicators.
- Used Amazon S3, AWS Glue, and Athena for storage and analytics.
- Built an interactive Streamlit dashboard covering 4,313 institutions in the latest validated quarter.
- Implemented CI/CD and scheduled data-availability checks using GitHub Actions.
- Deployed a public dashboard using validated portfolio snapshots.

**Technologies:** Python, Pandas, SQL, Amazon S3, AWS Glue, Amazon Athena, Parquet, Streamlit, Plotly, pytest, and GitHub Actions.

The project demonstrates my ability to work across the data engineering lifecycle, from collecting raw financial data to delivering analytical outputs that support investigation and decision-making.
