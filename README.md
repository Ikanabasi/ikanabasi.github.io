# Ikanabasi Akpan — Data & AI Portfolio

A GitHub Pages-ready personal portfolio built with a single `index.html` file. No server, build step or npm dependencies are required.

## Preview locally
Open `index.html` in your browser, or use VS Code Live Server.

## Deploy on GitHub Pages
1. Create a repository (for example, `portfolio`) and push `index.html` to its root.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Your site will be available at `https://YOUR_USERNAME.github.io/portfolio/` (or `https://YOUR_USERNAME.github.io/` if you use the special `YOUR_USERNAME.github.io` repository).

## Before publishing
- Replace `YOUR_EMAIL@example.com` in `index.html` with your preferred public contact email.
- Check your LinkedIn, GitHub and Streamlit demo links.
- Review project descriptions and status labels; edit the `projects` array in the script at the bottom of `index.html`.
- Featured project is **DataOps Sentinel**. Clicking a card opens a project details dialog; the gallery itself stays clean.
