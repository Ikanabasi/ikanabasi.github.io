Overview

The short version of what this project is and why I worked on it.

This was one of my first opportunities to work with operational data in a large technical environment. I supported analysis around network-performance KPIs and helped turn extracted data into reporting that could be reviewed more easily.

The experience helped me understand that data analysis is not only about calculations. The useful part is knowing what the metric represents, whether the source is reliable and how the result fits the operational question people are trying to answer.

The problem

What needed to be solved before thinking about tools or models.

What made it difficult

  • Network teams need many KPIs to understand performance.
  • Raw technical data has to be extracted and organized before it is useful to decision-makers.
  • Reporting has to make changes and exceptions easier to spot.

What I built / designed

  • Supported KPI extraction from telecom data sources including MAPS.
  • Prepared and analyzed performance data for reporting.
  • Worked with dashboards used to communicate network-performance information.

How it works

A simplified view of the system or workflow.
