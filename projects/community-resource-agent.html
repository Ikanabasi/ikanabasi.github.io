Overview

The short version of what this project is and why I worked on it.

This was a real operations problem rather than a portfolio exercise. The team needed to verify a large set of policies, and doing that record by record was slow and repetitive.

I used Python automation to handle the repeatable parts of the process, collect the needed information and make the final verification work easier to complete.

The problem

What needed to be solved before thinking about tools or models.

What made it difficult

  • Thousands of policies had to be checked.
  • The original process involved repetitive manual steps.
  • The work needed to be completed accurately without turning automation into a black box.

What I built / designed

  • Python automation for the repeatable verification steps.
  • Browser/data extraction logic using Selenium and BeautifulSoup where needed.
  • A structured workflow for working through the policy list and capturing results.
  • Checks that made it easier to review failed or incomplete cases separately.

How it works

A simplified view of the system or workflow.

Results so far

What is finished, working or learned at the current stage.

  • Roughly 5,000 policies were handled through the automated workflow.
  • The verification work was completed in about three days.
  • The project reduced repetitive manual effort and showed me how useful small, targeted automation can be in day-to-day operations.
