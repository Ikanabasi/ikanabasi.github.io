About me

What I’m learning, building and working towards.

I’m a Computer Science master’s student with a strong interest in data and applied AI. Most of what I’m working on now comes from one question: how do we make AI useful in real systems without blindly trusting it?

That has led me to projects around Text-to-SQL, AI agents, workflow automation, databases and human-in-the-loop systems. I enjoy understanding what happens behind the interface — where the data comes from, how the system makes decisions and what should happen when something goes wrong.

I’m still learning and building, and this portfolio is where I’ll document that progress as my projects become more complete.

Understand the data first I want to understand what the system is working with before adding AI on top of it.
Don’t blindly trust the model AI output should still be checked, validated and limited where necessary.
Build something I can explain I want to understand why each part of a system exists, not just connect tools together.

In progress 01

Making Text-to-SQL Safe to Trust on a Large Schema

I’m building a Text-to-SQL system that takes a natural-language question and generates SQL. Instead of automatically executing whatever the model produces, I’m building a safety layer that checks the generated query first. The current work includes PostgreSQL schema introspection, SQL parsing, query-type checks and table validation using SQLGlot.

Python PostgreSQL OpenAI SQLGlot LLM Guardrails
Current focus: building the validation layer before allowing generated SQL to reach the database.

Agentic AI Professional Networking Assistant

I’m designing an AI-assisted networking system for a legal professional. The idea is to help discover relevant professional contacts, research them, organize recommendations and keep track of relationships over time. The AI can help with the research and organization, but the person using the system still decides who to contact and what actions to take.
